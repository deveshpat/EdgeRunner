# EdgeRunner Free Persistent Compute Node

This Hugging Face Space hosts the persistent Linux compute and workspace engine for **EdgeRunner**.

### 🌟 Specifications (100% Free)
- **CPU**: 2 dedicated vCPUs
- **RAM**: 16 GB high-speed RAM
- **Disk**: 50 GB persistent storage
- **Uptime**: 24/7 continuous execution
- **Quota Cost**: $0 (preserves 100% of your Kaggle GPU quota!)

### 🚀 How to Connect to EdgeRunner
1. Create a new Space on [Hugging Face Spaces](https://huggingface.co/new-space).
2. Choose **Docker** as the SDK and upload this directory.
3. Copy your Space direct URL (e.g. `https://<your-username>-edgerunner.hf.space`).
4. In EdgeRunner, open **⚙ Settings** and paste your URL under **Remote Backend Connection**!
